# AntCrowd Domain Glossary

Use these names consistently across backend code, frontend copy, API payloads, and docs.

## Canonical actors

- `organization`
  The customer/company account that owns programs, VDP workflows, training workspaces, and team members.

- `researcher`
  The security tester using the platform to access programs, submit reports, manage payouts, and maintain a profile.

- `platform_admin`
  The AntCrowd-wide administrative account that invites external researchers, reviews verification submissions, and manages platform-level access.

## Researcher variants

- `internal researcher`
  Staff or approved internal contributors. Can self-register or be invited.

- `external researcher`
  Invite-only crowd researcher. Activated from a platform-admin email invitation.

## Organization roles

- `owner`
  Organization account owner.

- `admin`
  Organization administrator.

- `manager`
  Organization program manager or workspace manager.

- `member`
  Standard organization member.

## UI wording guidance

- Prefer `Organization` over `Client` or `Customer` in product UI unless a legal document requires the older term.
- Prefer `Researcher` over `Hacker` in platform UI and navigation.
- Use `Platform Admin` for AntCrowd-wide administration.
